# Янтарный берег — туристический гид по Калининграду 🌊💎

Полностью фронтендовый SPA-гид по Калининграду: **чистый HTML5 + CSS3 + JavaScript (ES6+)**, без фреймворков и без бэкенда. Все данные хранятся в JS-файлах в `/data`, состояние пользователя — в localStorage.

## Возможности

- **33 достопримечательности** с координатами, ценами, часами работы и фото
- Поиск, фильтры (категория / цена / сортировка) и три вида: сетка, список, **карта Leaflet**
- Избранное и прогресс «изучено мест»
- **Планировщик бюджета**: класс поездки, стиль отдыха, ручные ползунки, диаграммы Chart.js, сравнение со средним чеком туриста
- **Конструктор маршрута**: жадная оптимизация по дням, карта с линией маршрута, drag-and-drop, печать в PDF
- Инструменты: отсчёт до поездки, чек-лист, «Куда пойти сегодня?», факт дня, погодный виджет
- Отзывы (карусель + своя форма) и FAQ-аккордеон
- Тёмная/светлая тема и **двуязычность RU/EN** — переключение без перезагрузки, выбор сохраняется

## Запуск

Сайт работает даже без сервера — просто откройте `index.html`.
Для локального сервера:

```bash
python -m http.server 8642
# → http://localhost:8642
```

## Структура

```
index.html          — каркас SPA (шапка, футер, модалки)
css/style.css       — темы, компоненты, адаптив
data/
  attractions.js    — достопримечательности
  content.js        — факты, FAQ, конфиг бюджета
  translations.js   — словарь RU/EN
js/
  i18n.js, store.js, helpers.js, app.js
  views/            — по файлу на раздел
```

Фото — плейсхолдеры picsum.photos; замените поле `img` в `data/attractions.js` на реальные снимки.
